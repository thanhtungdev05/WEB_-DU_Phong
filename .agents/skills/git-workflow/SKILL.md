# Git workflow

1. Inspect `git status` and relevant diffs first.
2. Preserve unrelated local work.
3. Stage only intended files where practical.
4. Run relevant checks before commit.
5. Use concise imperative commit messages.
6. Never force-push unless explicitly requested and consequences are understood.
7. Confirm branch and remote before push.
8. Report committed/pushed files and remaining local changes.
