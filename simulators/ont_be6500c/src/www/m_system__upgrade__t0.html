Update & Restore
Factory Reset allows you to reset the firmware to its initial state using squashFS*

 images.

 (squashFS is a compressed read-only file system for Linux.)

This process will restore the firmware to its original configuration, erasing any custom settings or modifications.
If you’d like to save your current settings, please go to 'Config File Backup' to create a backup before proceeding.
