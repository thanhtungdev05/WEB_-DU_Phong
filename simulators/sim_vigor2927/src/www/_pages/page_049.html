Note:
  1. If Hardware Acceleration is enabled, the accelerated sessions will bypass Traffic Graph.
  2. Hardware Acceleration and WAN(Ethernet WAN) Budget can't be enabled simultaneously.
  3. When the wireless bandwidth limit is enable, wireless sessions will not add hardware acceleration.
  4. Hardware Acceleration supports Ethernet only.
  5. Hardware Acceleration does not support PPTP/L2TP.
  6. The exception type "WLAN Bridge" means hardware acceleration between wireless lan client and physical lan client.
