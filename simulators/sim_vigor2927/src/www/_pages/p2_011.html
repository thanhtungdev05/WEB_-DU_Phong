Note:
  1. Channel setting should not be changed while Wireless 2.4G WAN mode is in use.
  2. Channel setting should not be changed while Wireless WAN mode is in use.
  3. Isolate Member: Prevent the clients associated with this SSID from accessing each other.
  4. Isolate VPN: Block the wireless clients from accessing the VPN network and prevent wireless traffic being sent to VPN connections.
  5. Rate Control: Limit the total traffic rate of this SSID, can be a number between 100 to 50,000.
  6. Only the action "Force Down" in the Schedule Profile will be applied to WLAN, other actions will be ignored.
  7. When the router is in High Availability Hot-Standby method and it's the Secondary Router, the wireless function will be disabled.
