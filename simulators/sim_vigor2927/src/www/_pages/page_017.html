Note:
  1. The line speed setting of WAN interface is available only when According to Line Speed is selected as the Load Balance Mode.
  2. WAN1 and WAN2 cannot work simultaneously, so when one of the interfaces is enabled, the other will be disabled. WAN3 can only serve as the backup WAN for WAN1 or WAN2, depending on which is active.
  3. Latency,jitter,and packet-loss require setting Link Condition Detection in each WAN setting page.
  4. When WAN2 is enabled, LAN P6 port will be used as WAN2.
  5. Hide WAN3/WAN4 if the router does not support wireless WAN or no wireless device.
  6. When Physical Mode/Type of WAN2 is not Ethernet or WAN2 is disabled, P6 port will be used as LAN.
