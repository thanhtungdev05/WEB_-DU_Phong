Load-Balance/Route PolicyRoute Policy
1. We have received feedbacks that Route Policy always has a higher Priority than Inter-LAN Routing. To make the design more flexible, we make Priority configurable in this firmware version.
Hint: Set Policy Priority lower than routes in Routing Table so that Policy will NOT affect Inter-LAN Routing.
2. There are existing Policies inherited from the previous firmware version which does not support Priority,they will continue to operate as they did with the previous firmware.
3. Click Upgrade All button to start configuring Priority for each Policy. Please note that each Route Policy may have a different behavior than before.
