SMB Client Support List
The following compatibility test lists suggested SMB clients supported by Vigor router.

PlatformApplicationStatus

Y: Tested and is supported.
I: Supported but has some issue.
M: Has not been tested but might be supported.

Note:
  1. SMB service on Vigor router supports SMBv1 and SMBv2. Some applications on mobile devices might have compatibility issue with it, which use old and deprecated SMB commands. If you encounter login failure, fail to write, read or list files. Please use the suggested client above to prevent these issues.
