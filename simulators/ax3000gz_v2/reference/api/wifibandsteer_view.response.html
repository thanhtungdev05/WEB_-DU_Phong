    WLAN Band Steering

    Your data have been stored!

    For the normal use of bandsteering, the ssid name and password of 5g will be changed to be the same as that of 2.4G, which will cause the device connected to 5g ssid to be disconnected, and you need to reconnect the new ssid.

    After shutting down bandsteering, the ssid name and password of 5g will be restored to before bandsteering is turned on.

    2.4G threshold should be greater than 5G threshold of 10dBm.
