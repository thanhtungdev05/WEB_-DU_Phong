    Port Forwarding

    What should be noticed when configuring port forwarding?

    By using port forwarding, the accessing to hosts between assigned IP(s) and port(s) from WAN side is forwarded to one host of LAN side.
    This function allows users to access the virtual hosts of LAN side from WAN side.
